配置流程

免流(Jscloud) 的核心是「订阅地址 + 客户端」。按下面四步操作即可完成梯子/加速器上线，无需改系统深层设置。

第一步：确认套餐并复制订阅

在官网选定基础版、旗舰版或团队版，开通后进入账户页复制订阅链接。链接相当于节点清单，请勿公开转发。

第二步：下载对应客户端

Windows、macOS 常用 Clash / sing-box 系；Android 可用兼容 Meta 内核的应用；iOS 使用可导入订阅的商店客户端。详见客户端下载。

第三步：导入订阅并更新节点

打开客户端的订阅或 Profiles 栏，粘贴链接并更新。成功后会出现分区节点列表，名称通常含地区与线路类型。

第四步：选择节点并开启系统代理

先测延迟，优先选择数值低且丢包少的节点。开启客户端系统代理或 TUN 模式后，浏览器与应用会走加速通道。异常时关闭代理再切换节点。

操作注意

  1. 同一订阅可在套餐允许的设备数内重复导入，超出会挤占在线名额。
  2. 流媒体请使用带解锁标识的节点；普通线路可能仅适合网页。
  3. 游戏建议关闭自动选择，手动锁定 IPLC 或游戏优化线路。
  4. 更新客户端内核与订阅频率保持一致，避免规则集过期。

常见问题

免流(Jscloud) 是什么？和普通加速器有何不同？

免流(Jscloud) 是以机场订阅为核心的网络加速服务：你购买套餐后得到可更新的节点列表，再导入自己的客户端。与单一 App 加速器相比，你可以更换客户端、按地区选线，并把同一订阅用在电脑、手机或路由器上，额度以套餐流量和同时在线数为准。

如何完成机场订阅导入？

开通套餐后复制订阅 URL，在客户端的订阅管理中粘贴并点击更新。导入成功会显示节点分组。若列表为空，检查链接是否完整、客户端是否支持该订阅格式，然后在官网账户页重新复制。

客户端下载后如何配置系统代理？

Windows 与 macOS 先打开客户端的系统代理或 TUN；iOS 与 Android 允许添加 VPN 配置。连接后访问状态页确认出口 IP 已切换。若仅浏览器需要加速，可只开系统代理；游戏和会议更适合 TUN 或全局。

各套餐的流量、设备和解锁范围如何选？

基础版每月 100GB、3 台设备，适合网页和基础流媒体。旗舰版 300GB、5 台设备，含全节点原生解锁与 IPLC 游戏优化，并提供优先工单。团队版 1000GB、20 台设备，带 VIP 高带宽和定制路由。年付分别为 ¥150、¥350、¥850。

节点不稳定或流媒体无法播放怎么办？

先更新订阅，再换同地区其他节点，避开高峰拥塞线路。播放类服务必须使用套餐标明可解锁的节点，并关闭浏览器的旧代理扩展。持续失败时，旗舰版与团队版可通过 7x24 工单或客户经理排查。

官方下载和订阅安全吗？

请只在本官方网站核对客户端名称与导入步骤，不要把订阅链接发到公开群。链接泄露等于把流量额度交给他人。更换设备前在客户端删除旧配置，并在账户中观察在线会话。
